build step — just `index.html`, `style.css`, `main.js`, and the images in
`assets/images/`.

## Turning on GitHub Pages for this repo

1. On GitHub, go to this repo's **Settings → Pages**.
2. Under **Build and deployment**, set **Source** to "Deploy from a branch",
   branch `main`, folder `/ (root)`, then **Save**.
3. Within a minute or two the site will be live at
   `https://sthayappalli.github.io/grishmasajith/`.

To use a custom domain instead, add a `CNAME` file with the domain name and
point its DNS at GitHub Pages.
